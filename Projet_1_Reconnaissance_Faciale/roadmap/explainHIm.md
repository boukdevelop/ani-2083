# PROJET 1 - SEMAINE 1 (06 au 12 octobre 2026)

## Reconnaissance faciale intelligente des étudiants de la classe

### But du projet

Développer une application capable de détecter un visage à partir d'une webcam ou d'une image, puis d'identifier
l'étudiant correspondant parmi les personnes enregistrées dans une petite base constituée en classe.

### Données à collecter

5 étudiants par groupe ;
environ 20 à 40 images par personne ;
plusieurs orientations du visage, expressions, distances et conditions d'éclairage ;
utilisation strictement pédagogique et avec l'accord des personnes photographiées.

### Fonctionnalités minimales

ouvrir la webcam ou charger une image ;
détecter les visages et afficher une bounding box ;
afficher le nom de la personne reconnue et un score de confiance ;
retourner « Unknown / Inconnu » lorsque la confiance est insuffisante.
Test sur au moins une personne absente de la base

### Livrables
code Python complet ;
dataset organisé ;
notebook d'entraînement ;
fichier requirements.txt ;
README d'installation/utilisation ;
rapport court de 3 à 5 pages ;
captures d'écran ou courte démonstration.
